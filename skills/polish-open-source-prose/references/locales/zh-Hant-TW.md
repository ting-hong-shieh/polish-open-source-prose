# 台灣繁體中文編輯層（`zh-Hant-TW`）

本檔只處理台灣繁體中文的用字、標點與語域。保真與「不需要改就不改」的原則以
[../../SKILL.md](../../SKILL.md) 為準。

## 何時套用

符合下列任一條件時套用：

- 使用者明確指定繁體中文、台灣中文或 `zh-Hant-TW`；
- 檔案已有穩定的台灣用語與繁體字慣例；
- 專案明確將台灣列為這份在地化內容的目標市場。

只有「文字是繁體」並不足以推定目標是台灣。香港、澳門與其他繁體中文語系應使用
各自的 locale pack。來源中的官方名稱、引文、品牌、UI 標籤或搜尋關鍵字即使使用
簡體字，也不應自動轉換。

## 字形與標點

- 一般敘述使用全形中文標點；程式碼、CLI 命令、路徑、URL、版本號與資料格式維持
  半形。
- 中文引文優先使用 `「」`。專案已有一致格式、引用需逐字保留，或工具要求 ASCII
  引號時，沿用原格式。
- 中英文與數字之間是否留空格，依專案既有慣例決定，不當成硬性規則。
- 只在格式混亂或影響理解時統一標點，不做全檔機械替換。

## 地區詞彙

下表只列依語境容易選錯的詞，不是取代清單。一般軟體詞彙不必查表。

| 來源詞 | 台灣常用候選 | 判斷方式 |
| --- | --- | --- |
| 信息 | 資訊、訊息 | `information` 與 `message` 不同 |
| 数据 | 資料、數據 | 一般 data 用「資料」；統計量可用「數據」 |
| 文件 | 檔案、文件 | filesystem object 用「檔案」；document 用「文件」 |
| 项目 | 專案、項目 | project 與 list item 不同 |
| 配置 | 設定、組態、設定檔 | 依動作、系統架構或檔案種類選擇 |
| 通过 | 透過、通過 | 手段用「透過」；測試結果用「通過」 |
| 运行 | 執行、運作 | command 用「執行」；system state 可用「運作」 |
| 访问 | 存取、造訪 | data access 與 website visit 不同 |
| 代码 | 程式碼 | `code of conduct` 是「行為準則」 |

遇到不確定的用語時，依序查專案自己的繁中 UI 與詞彙表、上游產品的台灣官方譯名、
同領域台灣技術社群的穩定用法。不要為了「純中文」翻譯已被台灣開發者穩定使用的
API、套件、命令或英文術語。

## 法律、安全與引文

- 法律條款、授權、行為準則、安全步驟與揭露時程預設逐字保留，目標語系是
  `zh-Hant-TW` 也不翻譯。
- 使用者真的要修改政策時，只指出語意與風險差異，不當成一般潤稿。
- 引用他人文字時保留原文與原地區用語。

## 誤判防護

保留以下合理形式：

- 技術文件為了可搜尋性重複完整產品名或 API 名稱；
- 逐步操作中的平行句型；
- 錯誤訊息、規格和測試案例的固定結構；
- 為相容性、安全或法律精度而使用較正式的語氣；
- 作者刻意的台灣口語、幽默、語助詞或中英夾用；
- 承載範圍的「通常」「僅」「可能」「預設」「至少」。

不要刻意加入錯字、口頭禪、破碎句或不規則標點來假裝真人。
